# Labs — Bài thực hành cho sinh viên

Thư mục này chứa các bài thực hành độc lập (khác với các thư mục demo giảng
dạy ở cấp ngoài — `MongoDb/`, `Hdfs/`, `Spark/`...). Mỗi bài thực hành nằm
trong một thư mục con riêng, tự chứa đầy đủ dữ liệu và hướng dẫn, có thể copy
riêng để gửi cho sinh viên mà không cần các thư mục khác.
